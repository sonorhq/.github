# Sonor

Sonor is a music player for Subsonic and Navidrome servers, for macOS, Windows, Linux, iOS (with
CarPlay) and Android (with Android Auto). It isn't publicly available yet.

## Open-source components

Sonor's desktop apps include libmpv, FFmpeg and other libraries licensed under the GNU Lesser
General Public License. They are linked dynamically and can be replaced with your own builds.

The exact source code of those libraries, our patches, the build scripts and instructions to
rebuild and replace them are published for every release in
**[sonorhq/sonor › Releases](https://github.com/sonorhq/sonor/releases)**.

To ask for the source in another form, [open an issue](https://github.com/sonorhq/sonor/issues).
